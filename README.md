# Medicine Donation

**Seva First Innovation Challenge — Project Demonstration**

Medicine Donation is a proposed healthcare initiative designed to connect eligible unused medicine donations with authorised organisations and people who need assistance.

### Current Development Stage
Visual Demo / UI Prototype

This repository contains an initial static HTML, CSS and JavaScript demonstration. It is not a fully functional medicine donation platform.

### Project Objective
- Reduce avoidable medicine waste.
- Improve access to eligible medicines.
- Establish a responsible medicine verification workflow.
- Connect donors with authorised receiving organisations.

### Future Development
- Donor registration
- Medicine submission
- Authorised pharmacist verification
- Medicine inventory management
- Donation matching
- Donation status tracking
